# INTENT

## 무엇을 하는가

YouTube의 개별 영상과 재생목록을 한 화면의 작업 큐에서 관리하고 다운로드할 수 있는 데스크톱 애플리케이션을 만든다.

사용자는 여러 영상을 큐에 모아 두고 각 영상에 대해 받을 미디어의 선택 사항을 확인·조정하며, 다운로드가 어느 단계에 있는지 한눈에 확인할 수 있어야 한다.

## 왜 하는가

명령행이나 코드에서 영상 정보를 조회하고 포맷을 선택해 다운로드하는 방식은 한두 건을 처리할 때는 충분하지만, 여러 영상이나 재생목록을 반복해서 처리할 때는 현재 작업 목록과 각 항목의 선택 상태를 한눈에 보기 어렵다.

URL을 넣은 뒤 별도의 복잡한 절차 없이 작업 큐가 만들어지고, 필요한 정보를 바로 확인하면서 다운로드 순서와 항목별 선택을 직접 관리할 수 있는 전용 도구가 필요하다.

## 변하지 않는 원칙

- 작업의 중심은 개별 영상이 나열되는 **큐**다.
- 여러 영상의 상태와 설정을 한 화면에서 비교하고 조작할 수 있어야 한다.
- 어떤 영상·음성·자막을 받을지는 사용자가 확인하고 선택할 수 있어야 한다.
- URL을 추가한 뒤 정보 확인을 위해 별도의 복잡한 절차를 반복하지 않도록 한다.
- 기능을 넓게 모으기보다 YouTube 다운로드 작업에 필요한 기능을 작고 명확하게 유지한다.
- 화면은 장식보다 정보 밀도와 직접 조작성을 우선한다.

## 다루지 않는 것

- 범용 작업공간, 코드 편집기, 파일 탐색기, 터미널을 포함하는 통합 Workbench.
- YouTube 다운로드와 직접 관계없는 범용 데스크톱 생산성 기능.
- 다운로드한 영상의 편집·화질 개선 등 별도의 미디어 제작 도구 역할.
