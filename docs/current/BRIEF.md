> 버전: v0.1 · 작성일: 2026-09-28

# BRIEF

## 배경

기존 `youtube-kit`은 YouTube 영상과 재생목록의 정보를 조회하고, 영상·음성·자막을 선택해 다운로드하는 기능을 이미 제공한다. 현재 필요한 것은 이 기능을 반복적으로 사용하기 쉬운 Windows 데스크톱 UI로 감싸는 것이다.

특히 여러 URL 또는 재생목록을 처리할 때는 다음이 불편하다.

- 현재 처리할 영상이 무엇인지 한눈에 보기 어렵다.
- 각 영상에서 어떤 해상도·영상 코덱·음성·자막을 선택했는지 한 화면에서 비교하기 어렵다.
- URL을 추가한 뒤 다시 별도의 정보 조회 절차를 거치는 흐름은 반복 작업에 불필요한 단계가 된다.
- 재생목록은 영상 단위로 펼쳐져야 각 항목을 개별적으로 설정하고 순서를 조정할 수 있다.
- 다운로드 진행률과 완료 여부를 여러 항목에 걸쳐 동시에 확인할 수 있는 전용 화면이 필요하다.

기존 `workbench-kit`은 VS Code와 유사한 화면 스타일, Light/Dark 테마, 아이콘 사용 방식은 참고할 가치가 있지만, YouTube Downloader에 적용하기에는 shell과 공통 기능의 범위가 크다. 이번 앱은 다운로드 작업에 필요한 화면만 별도로 구성한다.

## 이번 버전에서 풀고 싶은 문제

v0.1에서는 다음 사용 흐름을 하나의 작고 명확한 데스크톱 앱에서 완성한다.

1. 사용자가 YouTube 영상 URL을 클립보드에서 URL 입력 영역에 붙여넣으면 해당 영상이 즉시 큐에 추가된다.
2. 큐에 추가된 항목은 자동으로 영상 정보를 조회하고, 조회 결과가 도착하는 대로 제목과 선택 가능한 미디어 정보를 갱신한다.
3. 재생목록 URL을 붙여넣으면 재생목록의 전체 영상이 개별 행으로 큐에 추가되고 각 행의 정보를 자동으로 조회한다.
4. 사용자는 각 행에서 영상 해상도, 영상 코덱, 음성, 자막을 선택할 수 있다.
5. 사용자는 큐의 행을 위/아래로 이동해 작업 순서를 조정할 수 있다.
6. 사용자는 각 행의 크기, 선택 상태, 다운로드 진행 상황, 완료 여부를 테이블에서 확인할 수 있다.
7. 화면은 다운로드 작업 자체에 집중하며, 불필요한 Workbench 기능 없이 간결하게 유지한다.
8. UI는 Light/Dark 두 테마와 일관된 아이콘 스타일을 제공한다.

## 하지 않을 것

- `workbench-kit`의 shell을 상속하거나 그대로 복사하지 않는다.
- Activity Bar, Explorer, Editor Tabs, Split Editor, Terminal, Markdown Viewer 같은 Workbench 기능을 v0.1 범위에 넣지 않는다.
- 카드가 여러 개 쌓이는 형태를 주 화면 구조로 사용하지 않는다.
- Light/Dark 이외의 추가 색상 테마를 만들지 않는다.
- 다운로드한 영상의 편집, 업스케일, 화질 개선 기능을 넣지 않는다.
- 큐 행의 드래그 앤 드롭 재정렬은 v0.1의 필수 범위로 두지 않는다. 위/아래 이동으로 충분하다.
- 별도의 모바일 앱이나 웹 서비스는 이번 버전 범위에 포함하지 않는다.
- 여러 행을 동시에 다운로드하지 않는다. 큐 순서대로 한 행씩 받는다.
- 일시정지·재개(이어받기)를 넣지 않는다.
- 앱을 다시 열 때 이전 큐를 복원하지 않는다.

## 완료 조건

다음 항목을 모두 직접 확인할 수 있으면 v0.1의 기획 범위가 완료된 것으로 본다.

- 패키징한 실행 파일로 Windows에서 앱을 실행할 수 있다.
- Light와 Dark 두 테마를 전환할 수 있다.
- 아이콘 중심의 간결한 툴바와 테이블 중심 화면이 표시된다.
- 개별 YouTube 영상 URL을 붙여넣으면 별도의 분석 버튼 없이 큐에 행이 추가된다.
- 추가된 행은 자동 정보 조회 후 제목과 선택 가능한 해상도·코덱·음성·자막 정보를 표시한다.
- 재생목록 URL을 붙여넣으면 재생목록의 전체 영상이 개별 큐 행으로 추가된다.
- 재생목록에서 추가된 각 영상도 자동으로 정보를 조회해 독립적으로 갱신된다.
- 각 행에서 해상도·코덱·음성·자막을 선택할 수 있다.
- 선택한 행을 위/아래로 이동할 수 있고 실제 큐 순서가 바뀐다.
- 큐의 각 행에서 다운로드 진행률과 완료/실패 상태를 확인할 수 있다.
- 선택한 미디어 조건으로 다운로드를 실행하고 완료 결과를 확인할 수 있다.
