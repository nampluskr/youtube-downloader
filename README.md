# youtube-downloader

## 개요

YouTube 영상과 재생목록을 한 화면의 작업 큐에 모아 두고 받는 Windows 데스크톱 앱이다.
URL을 붙여넣으면 바로 큐에 행이 생기고 영상 정보가 자동으로 채워진다. 재생목록은 영상
하나하나가 행으로 펼쳐진다. 행마다 받을 영상·음성·자막을 확인하고 고른 뒤, 큐 순서대로
받으면서 진행 상태를 한눈에 본다.

영상 정보 조회와 다운로드는 [youtube-kit](https://github.com/nampluskr/youtube-kit)이
맡고, 이 앱은 그 위에서 여러 영상을 다루는 작업 흐름과 화면을 제공한다. 다운로드
작업에 필요한 기능만 작고 간결하게 담는다.
